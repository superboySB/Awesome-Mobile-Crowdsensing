    (3) Make sure the type of each input variable is correctly specified; a float input variable should not be specified as torch.Tensor
    (4) Most importantly, the reward code's input variables must contain only attributes of the provided environment class definition (namely, variables that have prefix self.). Under no circumstance can you introduce new input variables.
    (5) Note the reward dict should contain initialization for big and small agent (like big_0, small_0). Small agents must act before big agent.
    (6) You need to record trajectory for big agent and small agent as well.
